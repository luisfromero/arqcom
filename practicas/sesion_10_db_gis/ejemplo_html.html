Este es un Título Principal (h1)

Los párrafos se definen con la etiqueta <p>. Este es el lugar donde escribes la mayor parte de tu texto. Puedes usar etiquetas como <strong> para dar importancia al texto (generalmente se ve en negrita) o <em> para enfatizarlo (generalmente se ve en cursiva).

Esto es un Subtítulo (h2)

Los títulos van desde <h1> (el más importante) hasta <h6> (el menos importante).

Listas: una forma de organizar información

Lista no ordenada (con viñetas)

  • Primer elemento de la lista.
  • Segundo elemento de la lista.
  • Tercer elemento.

Lista ordenada (con números)

  1. Primer paso.
  2. Segundo paso.
    • Esto es un sub-elemento anidado.
  3. Tercer paso.

Enlaces (Hipervínculos)

Los enlaces se crean con la etiqueta <a> (anchor). El atributo `href` especifica la URL de destino.
Puedes visitar Google para buscar más información. El atributo `target="_blank"` hace que el enlace se abra en una nueva pestaña.
